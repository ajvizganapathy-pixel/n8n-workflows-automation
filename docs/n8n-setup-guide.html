Overview

n8n is a free and open-source workflow automation platform that allows you to connect different apps and automate business processes. This guide covers the most common installation methods.

What is n8n?

n8n enables you to:

  • Automate repetitive tasks across multiple applications
  • Connect 400+ integrations and APIs
  • Build custom workflows with a visual editor
  • Self-host for complete data control
  • Deploy on your own infrastructure

Installation Methods

n8n can be installed using:

  • Docker (Recommended for quick setup)
  • npm (For development)
  • Cloud Platforms (AWS, Azure, DigitalOcean, etc.)
  • From Source (For advanced users)

Docker Installation

Docker is the recommended method for quick and clean installation.

Prerequisites

  • Docker Desktop installed and running
  • Docker Compose (included with Docker Desktop)
Note: Docker must be installed before proceeding. Visit docker.com for installation instructions.

Step-by-Step Installation

1

Create a Project Directory

Create a dedicated folder for your n8n installation:

mkdir n8n && cd n8n
2

Create docker-compose.yml

Create a docker-compose file with the following content:

version: '3'

services:
  n8n:
    image: n8nio/n8n
    ports:
      - "5678:5678"
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD=password123
    volumes:
      - n8n_data:/home/node/.n8n

volumes:
  n8n_data:
3

Start n8n Container

Launch the container using Docker Compose:

docker-compose up -d

This will download the image and start the container in the background.

4

Verify Installation

Check that the container is running:

docker-compose ps

You should see the n8n service with status "Up".

5

Access n8n Interface

Open your browser and navigate to:

http://localhost:5678

Log in with credentials: admin / password123

Important: Change the default password immediately in the n8n settings. Create a strong, unique password.

NPM Installation

For development environments or custom deployments.

Prerequisites

  • Node.js 18.10.0 or higher installed
  • npm or yarn package manager
1

Verify Node.js Installation

Check your Node.js version:

node --version && npm --version
2

Install n8n Globally

Install n8n as a global npm package:

npm install -g n8n
3

Start n8n Server

Run the n8n startup command:

n8n start

Wait for the server to start. You'll see the URL in the console output.

4

Access the Web Interface

By default, n8n runs at:

http://localhost:5678
Tip: Use n8n start --tunnel to automatically expose your instance to the internet via a secure tunnel for webhooks and external triggers.

Configuration & Setup

Customize your n8n installation for production use.

Environment Variables

Key environment variables for n8n configuration:

# Basic Authentication
N8N_BASIC_AUTH_ACTIVE=true
N8N_BASIC_AUTH_USER=admin
N8N_BASIC_AUTH_PASSWORD=your-secure-password

# Database Configuration
DB_TYPE=postgres
DB_POSTGRESDB_HOST=localhost
DB_POSTGRESDB_PORT=5432
DB_POSTGRESDB_DATABASE=n8n
DB_POSTGRESDB_USER=n8n
DB_POSTGRESDB_PASSWORD=password

# Server Configuration
N8N_HOST=0.0.0.0
N8N_PORT=5678
N8N_PROTOCOL=http

Using PostgreSQL Database

For production, PostgreSQL is recommended over SQLite:

version: '3'

services:
  n8n:
    image: n8nio/n8n
    environment:
      - DB_TYPE=postgres
      - DB_POSTGRESDB_HOST=postgres
      - DB_POSTGRESDB_PORT=5432
      - DB_POSTGRESDB_USER=n8n
      - DB_POSTGRESDB_PASSWORD=n8n_password
      - DB_POSTGRESDB_DATABASE=n8n

  postgres:
    image: postgres:15
    environment:
      - POSTGRES_USER=n8n
      - POSTGRES_PASSWORD=n8n_password
      - POSTGRES_DB=n8n

Verification & Testing

Ensure your n8n installation is working correctly.

Health Checks

1

Access Web Interface

Open browser and navigate to your n8n instance URL

2

Check Health Endpoint

Test the health check API endpoint:

curl http://localhost:5678/api/v1/health

Should return a 200 status with database status info.

3

Create First Workflow

Create a simple test workflow to verify functionality

  • Click "New Workflow"
  • Add a "Manual" trigger node
  • Add any node (e.g., "Set" node)
  • Save and execute
Success! If you can log in, access the dashboard, and create a workflow, your n8n installation is working correctly.

Troubleshooting

Common issues and solutions:

Cannot Access Web Interface

Issue

Browser shows "Connection refused" or timeout error

Solutions

  • Verify n8n is running: docker-compose ps or check process list
  • Check firewall rules for port 5678
  • Ensure correct URL: http://localhost:5678
  • Check logs: docker-compose logs n8n

Database Connection Error

Issue

Error connecting to PostgreSQL or database initialization fails

Solutions

  • Verify database credentials match environment variables
  • Ensure PostgreSQL container is running
  • Check database user has correct permissions
  • Review logs for specific error messages

High Memory Usage

Issue

n8n consuming excessive memory resources

Solutions

  • Limit Node.js memory: Set --max-old-space-size=2048
  • Optimize workflows: Remove unnecessary loops
  • Clean up old logs and data
  • Use PostgreSQL instead of SQLite for better performance

SSL Certificate Issues

Issue

"SSL: CERTIFICATE_VERIFY_FAILED" error with webhooks

Solutions

  • Ensure HTTPS is properly configured
  • Set NODE_TLS_REJECT_UNAUTHORIZED=0 for testing only
  • Use valid SSL certificates in production
  • Verify external service SSL configuration
